# Agent Demo

一个从零手写的极简 AI 编码代理，用来边做边学 Agent 的核心原理。

## 这是什么

这是一个最小可运行的 **AI Agent**：它接收一个任务，自己决定调用哪些工具，观察结果，然后继续决策，直到完成任务。

核心循环只有一句话：

> 模型决策 → 调用工具 → 观察结果 → 继续决策

## 功能

- **对话式任务输入**：用自然语言描述任务
- **工具调用**：读写文件、执行 shell 命令
- **沙箱隔离**：所有操作限制在 `sandbox/` 目录内
- **安全护栏**：路径越界检测、危险命令拦截、执行超时、最大步数限制
- **多模型支持**：通过 OpenAI 兼容接口，可接 DeepSeek、OpenAI、通义千问等
- **自我纠错**：工具报错后，模型能根据错误信息调整策略
